# Terra: запуск из ZIP на Windows

## Требуется один раз установить

- Windows 10 22H2+; Node.js LTS.
- Rust stable с MSVC toolchain и Visual Studio Build Tools (**Desktop development with C++**, MSVC, Windows 10 SDK).
- Microsoft Edge WebView2 Runtime.
- Ollama и хотя бы одна локальная модель.

## Первый запуск и последующие запуски

1. Скачай ZIP ветки `terra-skeleton` и распакуй его в папку. Для обновления можно распаковать свежий ZIP в чистую папку и затем удалить старую папку проекта.
2. Убедись, что приложение Ollama запущено. Список моделей проверяется командой `ollama list`; Terra не скачивает их автоматически.
3. Дважды щёлкни `Start-Terra.bat` в корне распакованного проекта. Скрипт сам: задаёт рабочую временную папку для Rust linker, при необходимости устанавливает npm-зависимости и Tauri CLI, генерирует иконки из `resources/icons/terra-source.svg`, собирает голосовой `jarvis-app.exe`, затем запускает Terra. Оставь окно консоли открытым.

При первом запуске Cargo скачает/соберёт зависимости и это может занять время. При следующих запусках используются локальные кэши; повторная установка npm-пакетов пропускается, если Vite уже установлен. Модели Ollama остаются доступными независимо от ZIP.

В интерфейсе открой **Текстовый чат**, нажми **Обновить** и выбери установленную модель. Кнопка **Запустить** относится к отдельному голосовому runtime, который скрипт собирает заранее; сам чат пока не использует микрофон и не озвучивает ответы.

## Что занимает место

- `frontend/node_modules` — JS-зависимости внутри папки проекта.
- `target` — Rust build-кэш внутри проекта.
- `%USERPROFILE%\.cargo` — глобальный кэш Rust-зависимостей и Tauri CLI.
- Модели Ollama — отдельное хранилище Ollama; удаление распакованного ZIP их не удалит.

Для очистки старых копий закрой Terra и удали старые папки проекта. Не удаляй `%USERPROFILE%\.ollama`, если хочешь сохранить модели. Новая распакованная копия создаст собственные `node_modules` и `target`; Cargo-кэш и модели Ollama переиспользуются.

## Whisper Small для режима разговора

Терра распознаёт слово-активатор и команды через Vosk (быстро, по грамматике), а свободную речь в диалоге — через Whisper Small. Whisper загружается только после цепочки **«Терра» → «Да» → «Разговор»**, поэтому на обычные команды он не влияет.

Установка (один раз, из корня проекта):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup-whisper.ps1
```

Скрипт скачивает в `resources\whisper`:

- `whisper-cli.exe` и его DLL из релиза whisper.cpp;
- модель `ggml-small.bin` (мультиязычная, понимает русский).

Можно поставить вручную: бинарник — из [релизов whisper.cpp](https://github.com/ggml-org/whisper.cpp/releases) (`whisper-bin-x64.zip`), модель — [ggml-small.bin](https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin).

Настройки (необязательные):

- `whisper_enabled` — `true`/`false`;
- `whisper_model`, `whisper_exe` — свои пути к модели и бинарнику;
- `whisper_language` — пусто = язык интерфейса, `auto` = определять язык каждой реплики (нужно, если в речи есть английские слова и фразы);
- `whisper_prompt` — подсказка со словарём для редких слов и терминов.

Границы фраз: команда закрывается после 0.9 с тишины, реплика в разговоре — после 2.2 с, поэтому можно спокойно делать паузы посреди мысли. Текст больше не обрывается из‑за того, что Vosk не смог разобрать сложное слово: в разговоре звук расшифровывает Whisper.

Если бинарника или модели нет, Terra один раз напишет причину в лог при старте разговора и продолжит работать на тексте Vosk — диалог не ломается. В интерфейсе чата во время расшифровки видно состояние «Расшифровываю через Whisper…».
